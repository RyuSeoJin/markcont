# 📘 markcont 사용 안내서

markcont(**mark**down **cont**roller)는 마크다운 파일을 보기 좋게 보고, 그 자리에서 바로 고치는 프로그램입니다.
이 안내서는 처음 쓰는 분이 순서대로 따라 할 수 있게 정리했습니다.

> [!TIP]
> 처음 사용 안내(튜토리얼)는 오른쪽 위 **⋯ → 처음 사용 안내 다시 보기**에서 언제든 다시 볼 수 있습니다.

---

## 1️⃣ 파일 열기

| 방법 | 이렇게 하세요 |
|:---|:---|
| 파일 하나 | 위쪽 **파일 열기** (<kbd>Ctrl</kbd>+<kbd>O</kbd>) |
| 폴더 통째로 | 위쪽 **폴더 열기** — 사이드바에 폴더 트리가 나옵니다 |
| 끌어다 놓기 | `.md` 파일이나 폴더를 창 위에 놓으세요 |
| 더블클릭 | PC 프로그램을 설치했다면 `.md` 파일을 더블클릭 |
| 최근 문서 | 처음 화면과 사이드바의 **최근 폴더 · 최근 파일** |

> [!NOTE]
> 파일은 내 기기 안에서만 읽습니다. 어디에도 올라가지 않습니다.

### 이 파일은 어디에 있나요?

문서 제목 바로 위에 **파일 위치**가 나옵니다. 위쪽 제목 표시줄에 마우스를 올려도 보입니다.

| 연 방법 | 보이는 위치 |
|:---|:---|
| PC 프로그램 | 전체 경로 (`C:\Users\…\a.md`) · **경로 복사** · **폴더에서 보기** |
| 폴더 열기로 연 폴더 안의 파일 | `폴더이름/안쪽/a.md` · **경로 복사** |
| 브라우저에서 파일 하나만 연 경우 | 파일 이름만 (브라우저는 보안 때문에 전체 위치를 알려주지 않음) |
| 끌어다 놓은 복사본 · 최근 문서 기록 | 원래 위치를 모른다는 안내 (저장하면 새 파일로) |

- 열어 둔 폴더 안의 파일을 **파일 열기**로 따로 열면, 그 폴더 트리의 파일로 열립니다.

## 2️⃣ 사이드바 쓰기

왼쪽 위 <kbd>☰</kbd> 단추로 사이드바를 열고 닫습니다. 경계를 끌면 폭이 바뀌고, 더블클릭하면 원래 폭으로 돌아갑니다.

### 파일 탭

- 폴더를 열면 **md 파일이 있는 폴더만** 트리로 보여줍니다. 폴더 옆 숫자는 그 안의 md 파일 개수입니다.
- **폴더 열기를 또 하면 폴더가 하나 더 더해집니다.** 여러 폴더가 각각 맨 위 항목으로 쌓여 보입니다(작업 공간). 같은 폴더를 다시 열면 이미 열린 폴더로 이동합니다.
- 맨 위 폴더를 오른쪽 클릭 → **이 폴더 닫기**를 누르면 목록에서만 빠집니다. 파일은 그대로 있습니다.
- PC 프로그램은 다음에 켤 때 열어 두었던 폴더들을 다시 엽니다.
- 폴더 이름을 누르면 접히고 펼쳐집니다. 접은 상태는 기억됩니다.
- 파일이 많으면 **파일 이름으로 찾기** 칸이 나옵니다.
- 키보드: <kbd>↑</kbd> <kbd>↓</kbd> 이동, <kbd>Enter</kbd> 열기, <kbd>F2</kbd> 이름 바꾸기, <kbd>Del</kbd> 삭제

### 오른쪽 클릭 메뉴

파일이나 폴더를 **오른쪽 클릭**하거나, 줄 끝의 **⋯** 단추를 누르세요.

| 메뉴 | 하는 일 |
|:---|:---|
| 새 문서 · 새 폴더 | 그 폴더 안에 새로 만듭니다. 새 문서는 바로 편집 화면으로 열립니다 |
| 이름 바꾸기 | 파일 · 폴더 이름을 바꿉니다 |
| 경로 복사 | 파일 위치를 복사합니다 |
| 삭제 | PC 프로그램은 **휴지통**으로, 브라우저는 **완전히** 지웁니다 |

> [!WARNING]
> 브라우저(Chrome · Edge)에서 지운 파일은 휴지통으로 가지 않아 되살릴 수 없습니다. 지우기 전에 한 번 더 확인하세요.

### 목차 탭

문서의 제목(`#`)으로 목차를 만듭니다. 읽고 있는 위치가 강조되고, 누르면 그 제목으로 이동합니다.

## 3️⃣ 읽기 편하게 보기

| 기능 | 어디에 | 설명 |
|:---|:---|:---|
| 보기 설정 | 위쪽 **Aa** 단추 | 글자 크기, 고딕 · 명조, 본문 폭, 알림 상자 모양, 코드 줄 번호, 저장 전 확인 |
| 언어 | 보기 설정(**Aa**) → 언어, 또는 처음 사용 안내의 첫 화면 | 한국어 · English 를 바꿉니다 |
| 밝게 · 어둡게 | 위쪽 ☾ / ☀ 단추 | 다크 모드 |
| 제목 접기 | 제목 옆 ⌄ 단추 | 그 제목 아래 내용을 접습니다 |
| 링크 복사 | 제목 옆 **#** 단추 | `[제목](#제목)` 링크를 복사합니다 |
| 문서에서 찾기 | <kbd>Ctrl</kbd>+<kbd>F</kbd> | 찾은 곳을 강조하고 차례로 이동합니다 |
| 집중 모드 | <kbd>Ctrl</kbd>+<kbd>.</kbd> | 본문만 남깁니다. <kbd>Esc</kbd>로 끝 |
| 코드 크게 보기 | 코드 블록 머리줄의 ⤢ | 코드를 화면 가득 봅니다 |
| 다이어그램 크게 보기 | 다이어그램 오른쪽 위 ⤢ | 휠 · 두 손가락으로 확대 · 축소, 끌어서 옮기기, 「화면에 맞추기」 |

> [!NOTE]
> **인터넷에 접속하는 경우** — 명조 글꼴(Google Fonts), 유튜브 썸네일, 문서 안의 인터넷 그림, HTML로 저장한 파일의 스타일(CDN)은 외부 서버에서 받아 오며, 이때 내 IP 주소가 그 서버에 전달됩니다. 그 밖에는 인터넷 없이 동작합니다.

## 4️⃣ 고치기 (실시간 편집)

위쪽 **편집** (<kbd>Ctrl</kbd>+<kbd>E</kbd>)을 누르면 왼쪽에 원본, 오른쪽에 결과가 나란히 나옵니다.

- 입력하는 즉시 오른쪽 결과와 목차가 바뀝니다.
- 지금 고치는 부분이 오른쪽에 **테두리**로 표시됩니다.
- 오른쪽 결과를 누르면 왼쪽 원본의 그 줄로 이동합니다.
- 위쪽 **편집만 · 나란히 · 미리보기**로 보기 방식을 바꿉니다.
- 미리보기의 체크박스를 누르면 원본의 `[ ]` 도 `[x]` 로 바뀝니다.

### 편집 단축키

| 단축키 | 하는 일 |
|:---|:---|
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | 굵게 |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | 기울임 |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | 링크 |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | 들여쓰기 / 내어쓰기 |
| <kbd>Enter</kbd> | 목록 · 인용을 다음 줄에 이어 씀 (빈 줄에서 누르면 끝냄) |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 저장 |

편집 도구 모음에는 제목, 목록, 체크리스트, 알림 상자, 코드 블록, 표, 그림 넣기 단추가 있습니다.

### 어디까지 고쳤는지 보기 · 되돌리기

| 보이는 것 | 뜻 |
|:---|:---|
| 줄 번호 옆 **초록 막대** | 저장한 뒤 새로 쓴 줄 |
| 줄 번호 옆 **파란 막대** | 저장한 뒤 고친 줄 |
| 줄 번호 옆 **빨간 ▸** | 이 자리에서 줄을 지움 |
| 아래 상태 줄 **바뀐 줄 N개 · 보기** | 눌러서 바뀐 내용 창 열기 |

편집 도구 모음의 **기록** 단추(<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd>)로 창을 엽니다.

- **저장 후 바뀐 내용**: 저장한 내용과 지금을 `−`(지운 줄) / `+`(새로 쓴 줄)로 비교합니다. 바뀐 덩어리마다 **이 부분 되돌리기**, 아래에 **저장한 상태로 모두 되돌리기**가 있습니다.
- **되돌리기 기록**: 고친 내용이 1초마다 시간과 함께 기록됩니다. 시점을 누르면 **그때로 돌아가면 지금 문서가 어떻게 바뀌는지** 먼저 보여주고, **되돌리기**를 누르면 돌아갑니다.
- 되돌린 뒤에도 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 로 취소할 수 있습니다. 기록은 프로그램을 닫으면 사라집니다.

## 5️⃣ 저장과 내보내기

| 하는 일 | 방법 |
|:---|:---|
| 기존 파일에 저장 | **저장** 단추 또는 <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| 새 파일로 저장 | 저장 단추 옆 **▾ → 새 파일로 저장…** 또는 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> — 원래 파일은 그대로 두고, 이후로는 새 파일을 고칩니다 |
| 다른 뷰어용으로 | 저장 단추 옆 **▾ → 다른 뷰어용으로 저장…** — markcont 전용 문법을 표준 문법으로 바꾼 사본 (GitHub · VS Code 에서도 같게 보이게, 원래 파일은 그대로) |
| HTML 파일로 | **⋯ → HTML 파일로 저장** — 보이는 그대로 한 파일로 |
| PDF로 | **⋯ → 인쇄 · PDF로 저장** 에서 "PDF로 저장" 선택 |

- 파일 열기 · 폴더 열기로 연 파일은 **원래 파일에 바로 저장**됩니다.
- 저장하기 전에 **무엇이 바뀌는지 먼저 보여주고 한 번 더 묻습니다** (취소 · 새 파일로 저장 · 저장). 끄려면 **Aa → 저장하기 전에 바뀐 내용 확인**을 끄거나, 확인 창의 **다음부터 묻지 않기**를 체크하세요.
- 원래 위치를 알 수 없는 문서(사용 안내서, 새 문서, 끌어다 놓은 일부 파일)는 저장할 때 자동으로 **새 파일로 저장**이 열립니다.
- 열어 둔 폴더 안에 새 파일로 저장하면 그 폴더 트리에 바로 나타납니다.
- 문서에 markcont 전용 문법(`==형광펜==`, `[!INFO]`, ```` ```flow ```` 등)이 있으면 문서 위쪽에 **⚠ 다른 뷰어에서 다르게 보이는 곳 N곳** 이 보입니다. 누르면 그 줄 목록이 나오고, 줄을 누르면 그 위치로 가며, **이 문서를 표준 문법으로 바꾸기**로 한 번에 바꿀 수도 있습니다.
- 다른 프로그램이 파일을 고치면 markcont가 **자동으로 다시 불러옵니다.** 저장 안 한 내용이 있을 때는 덮어쓰지 않고 알려줍니다.

## 8️⃣ Claude와 연결 (PC 프로그램)

Claude Desktop · Claude Code에서 markcont의 문서를 바로 고치게 할 수 있습니다 (MCP 연결).

1. **폴더 열기**로 작업할 폴더를 엽니다. Claude는 **열어 둔 폴더 안의 마크다운 · 텍스트 파일만** 다룰 수 있습니다.
2. **⋯ → Claude와 연결 (MCP)** 에서 **Claude Desktop에 연결**을 누르고 Claude Desktop을 다시 엽니다. Claude Code는 창에 나온 명령을 터미널에서 한 번 실행합니다.
3. Claude 앱에서 요청합니다. 예: "markcont에서 보고 있는 문서를 작성 규칙에 맞게 다듬어 줘", "선택한 부분을 표로 바꿔 줘"

| 보이는 것 | 뜻 |
|:---|:---|
| 위쪽 **🔌 Claude가 ○○ 고침** | Claude가 방금 읽거나 고친 파일 |
| 바뀐 곳이 **노랗게 빛남** | Claude(또는 다른 프로그램)가 바꾼 곳 |
| 알림의 **바뀐 내용 보기** | −/+ 비교와 **이 변경 되돌리기** |
| **기록** 창의 "Claude가 고침" | 그 전으로 되돌릴 수 있는 시점 (markcont를 닫으면 기록이 사라짐) |

> [!NOTE]
> 연결하면 Claude가 읽은 문서 내용이 Anthropic으로 보내져 처리됩니다. Claude 앱은 도구를 쓰기 전에 허락을 묻습니다. markcont는 구독이나 API 키를 쓰지 않습니다.

> [!WARNING]
> **남이 보낸 문서는 조심하세요.** 문서 안에 숨겨진 지시문(예: "다른 문서도 모두 바꿔라")을 AI가 따를 수 있습니다(프롬프트 주입). markcont는 삭제 · 이름 바꾸기 · 명령 실행을 막고 열어 둔 폴더 안에서만 동작하게 해서 피해를 줄이지만, 믿을 수 없는 문서가 든 폴더는 연결한 채로 AI에게 맡기지 마세요. 잘못 고쳐졌다면 **바뀐 내용 보기 · 되돌리기 기록**으로 되돌릴 수 있으나, 저장된 경우에는 복구가 불가능하니 조심해서 이용해주세요.

## ❓ 자주 묻는 질문

<details>
<summary>저장했는데 원래 파일이 안 바뀌었어요</summary>

끌어다 놓거나 예전 방식으로 연 파일은 원래 파일에 쓸 권한이 없어 **다운로드 폴더**에 저장됩니다. **파일 열기** 단추나 **폴더 열기**로 다시 열면 원래 파일에 저장됩니다.

</details>

<details>
<summary>폴더 트리에 어떤 폴더가 안 보여요</summary>

md 파일이 하나도 없는 폴더와 이름이 `.` 으로 시작하는 폴더, `node_modules` 는 숨깁니다.

</details>

<details>
<summary>문서를 보기 좋게 쓰는 방법이 궁금해요</summary>

**⋯ → [마크다운 작성 규칙](마크다운-작성-규칙.md)**을 여세요. AI에게 그 문서를 같이 주고 "이 규칙대로 다시 써 줘"라고 하면 됩니다.

</details>
