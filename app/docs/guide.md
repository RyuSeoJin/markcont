# markcont 사용 안내서

markcont(**mark**down **cont**roller)는 마크다운 파일을 보기 좋게 보고, 그 자리에서 바로 고치는 프로그램입니다.
이 안내서는 처음 쓰는 분이 순서대로 따라 할 수 있게 정리했습니다.

> [!TIP]
> 처음 사용 안내(튜토리얼)는 오른쪽 위 **⋯ → 도움말 → 처음 사용 안내 다시 보기**에서 언제든 다시 볼 수 있습니다.

---

## 1️⃣ 파일 열기

| 방법 | 이렇게 하세요 |
|:---|:---|
| 이름으로 바로 열기 | <kbd>Ctrl</kbd>+<kbd>O</kbd> (**⋯ → 빠른 열기 · 명령**) 를 누르고 이름 일부나 초성(`ㄱㅎㅅ`)을 쳐서 <kbd>Enter</kbd> |
| 파일 하나 | 위쪽 **파일 열기**, 또는 <kbd>Ctrl</kbd>+<kbd>O</kbd> 를 두 번 |
| 폴더 통째로 | 위쪽 **폴더 열기** — 사이드바에 폴더 트리가 나옵니다 |
| 끌어다 놓기 | `.md` 파일이나 폴더를 창 위에 놓으세요 |
| 더블클릭 | PC 프로그램을 설치했다면 `.md` 파일을 더블클릭 |
| 최근 문서 | 처음 화면과 사이드바의 **최근 폴더 · 최근 파일** |

> [!NOTE]
> 파일은 내 기기 안에서만 읽습니다. 어디에도 올라가지 않습니다.

### 빠른 열기 · 명령 (<kbd>Ctrl</kbd>+<kbd>O</kbd>)

열어 둔 폴더의 파일, 지금 문서의 제목, 메뉴의 명령을 한 창에서 찾습니다. <kbd>↑</kbd> <kbd>↓</kbd> 로 고르고 <kbd>Enter</kbd> 로 엽니다.

| 이렇게 치면 | 찾는 것 |
|:---|:---|
| 이름 일부 · 초성 | 파일: `기획` · `ㄱㅎㅅ` → 기획서, `fp` → feature-proposals (낱말 첫 글자만 띄엄띄엄) |
| `>` 로 시작 | 명령: `>저장` · `>번호` · `>dark` (한국어 · 영어 이름 모두) |
| `#` 으로 시작 | 지금 문서의 제목: `#결정` |
| 아무것도 치지 않음 | 이번에 열었던 순서대로 파일 |

- 대소문자, 라틴 악센트(`cafe` → café), 전각 · 반각(`ＡＢＣ` = ABC), 히라가나 · 가타카나(`きかく` → キカク)를 가리지 않습니다. 맥에서 만든 한글 이름도 찾습니다.
- 창이 열린 채 <kbd>Ctrl</kbd>+<kbd>O</kbd> 를 한 번 더 누르면 **다른 파일 열기** 창이 뜹니다.
- 사이드바의 **파일 이름으로 찾기** 칸도 초성 · 악센트를 같은 방식으로 맞춥니다.

### 이 파일은 어디에 있나요?

문서 제목 바로 위에 **파일 위치**가 나옵니다. 위쪽 제목 표시줄에 마우스를 올려도 보입니다.

| 연 방법 | 보이는 위치 |
|:---|:---|
| PC 프로그램 | 전체 경로 (`C:\Users\…\a.md`) · **경로 복사** · **폴더에서 보기** |
| 폴더 열기로 연 폴더 안의 파일 | `폴더이름/안쪽/a.md` · **폴더 안 경로 복사** |
| 브라우저에서 파일 하나만 연 경우 | 파일 이름만 (브라우저는 보안 때문에 전체 위치를 알려주지 않음) |
| 끌어다 놓은 복사본 · 최근 문서 기록 | 원래 위치를 모른다는 안내 (저장하면 새 파일로) |

- 열어 둔 폴더 안의 파일을 **파일 열기**로 따로 열면, 그 폴더 트리의 파일로 열립니다.

## 2️⃣ 사이드바 쓰기

왼쪽 위 <kbd>☰</kbd> 단추로 사이드바를 열고 닫습니다. 경계를 끌면 폭이 바뀌고, 더블클릭하면 원래 폭으로 돌아갑니다.

### 파일 탭

- 폴더를 열면 **md 파일이 있는 폴더만** 트리로 보여줍니다. 폴더 옆 숫자는 그 안의 md 파일 개수입니다.
- **폴더 열기를 또 하면 폴더가 하나 더 더해집니다.** 여러 폴더가 각각 맨 위 항목으로 쌓여 보입니다(작업 공간). 같은 폴더를 다시 열면 이미 열린 폴더로 이동합니다.
- 맨 위 폴더를 오른쪽 클릭 → **이 폴더 닫기**를 누르면 목록에서만 빠집니다. 파일은 그대로 있습니다.
- PC 프로그램은 다음에 켤 때 열어 두었던 폴더들을 다시 엽니다.
- 폴더 이름을 누르면 접히고 펼쳐집니다. 접은 상태는 기억됩니다.
- 파일이 많으면 **파일 이름으로 찾기** 칸이 나옵니다. 초성(`ㄱㅎㅅ`)으로도 찾습니다.
- 키보드: <kbd>↑</kbd> <kbd>↓</kbd> 이동, <kbd>Enter</kbd> 열기, <kbd>F2</kbd> 이름 바꾸기, <kbd>Del</kbd> 삭제

### 오른쪽 클릭 메뉴

파일이나 폴더를 **오른쪽 클릭**하거나, 줄 끝의 **⋯** 단추를 누르세요.

| 메뉴 | 하는 일 |
|:---|:---|
| 새 문서 · 새 폴더 | 그 폴더 안에 새로 만듭니다. 새 문서는 바로 편집 화면으로 열립니다 |
| 이름 바꾸기 | 파일 · 폴더 이름을 바꿉니다 |
| 경로 복사 | PC 프로그램은 전체 경로(`C:\Users\…\a.md`)를 복사합니다. 탐색기 주소창에 그대로 붙여 넣을 수 있습니다. 브라우저는 **폴더 안 경로 복사**로, 연 폴더 안에서의 경로만 복사합니다 |
| 사이드바에서 숨기기 | 파일은 그대로 두고 사이드바 목록에서만 뺍니다. 빠른 열기 · 찾기 · 링크는 그대로 됩니다. 맨 위 폴더의 ⋯ → **숨긴 항목 보기**를 누르면 흐리게 다시 보이고, 그 줄의 ⋯ → **다시 보이기**로 되돌립니다. **따로 연 파일**은 이번에만 숨기고, 목록의 **숨긴 파일 N개 보기**를 누르거나 그 파일을 다시 열면 다시 보입니다 |
| 목록에서 빼기 | **따로 연 파일**에만 있습니다. 파일은 그대로 두고 markcont 목록에서 아예 뺍니다. 숨기기와 달리 빠른 열기 · 찾기에도 나오지 않고, 그 파일을 다시 열면 다시 들어옵니다. 폴더째 빼려면 맨 위 폴더의 **이 폴더 닫기**를 쓰세요 |
| 삭제 | PC 프로그램은 **휴지통**으로, 브라우저는 **완전히** 지웁니다 |

> [!WARNING]
> 브라우저(Chrome · Edge)에서 지운 파일은 휴지통으로 가지 않아 되살릴 수 없습니다. 지우기 전에 한 번 더 확인하세요.

**이름을 바꾸면 링크도 같이**: 파일 · 폴더 이름을 바꾸면, 그 문서를 가리키던 `[[링크]]` · `[글](파일.md)` 를 새 이름으로 바꿀지 묻습니다. 바뀌는 문서와 줄을 먼저 보여 주고, 코드 블록 · `코드` 안의 예시는 건드리지 않습니다. 문서의 **제목**을 바꿔 저장할 때도 그 제목을 가리키던 `[글](문서.md#제목)` · `[[문서#제목]]` 을 고칠지 묻습니다. 바꾼 문서는 저장 기록에 남습니다. (PC 프로그램 · Chrome · Edge)

### 목차 탭

문서의 제목(`#`)으로 목차를 만듭니다. 읽고 있는 위치가 강조되고, 누르면 그 제목으로 이동합니다.

본문에 `[[_TOC_]]` 한 줄을 쓰면 그 자리에도 목차가 나옵니다. 인쇄 · PDF에도 들어갑니다.

### 찾기 탭 (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>)

열어 둔 폴더의 **모든 문서에서** 글을 찾습니다. 찾은 줄이 문서별로 묶여 나오고, 줄을 누르면 그 문서의 그 자리로 갑니다(보기 화면에서는 찾은 글자가 강조되고, 편집 중이면 원본에서 그 글자가 골라집니다).

| 단추 | 하는 일 |
|:---:|:---|
| `Aa` | 대소문자를 구분합니다 |
| <code><u>ab</u></code> | 단어 단위로 찾습니다 (`기획` 은 `기획 문서` 에서는 찾고 `기획서` 에서는 찾지 않음) |
| `.*` | 정규식으로 찾습니다 (예: `결[제정]`) |

- 빠른 열기처럼 대소문자 · 라틴 악센트 · 전각 · 반각 · 히라가나 · 가타카나를 맞춰 비교하고, 맥에서 만든 문서도 찾습니다.
- 한글 자음(`ㄱㅎ`)은 그 자음으로 시작하는 글자와도 맞습니다 (`ㄱㅎ` → 기획).
- 지금 문서는 저장하지 않은 편집 내용까지 찾습니다. 문서마다 200줄, 모두 3000줄까지 보여 줍니다.
- 결과에서 <kbd>↑</kbd> <kbd>↓</kbd> 로 옮기고 <kbd>Enter</kbd> 로 엽니다. 문서 이름을 누르면 그 문서의 결과를 접습니다.

### 연결 탭

지금 문서와 이어진 문서를 봅니다. 줄을 누르면 그 문서 · 그 줄로 갑니다.

| 묶음 | 보이는 것 |
|:---|:---|
| 이 문서를 가리키는 문서 | 이 문서로 링크한 문서와 그 줄 (백링크) |
| 이 문서가 가리키는 문서 | 이 문서에서 링크한 문서 |
| 깨진 링크 · 그림 | 찾지 못한 문서 · 제목 · 그림, 그리고 **markcont에서만 열림** 링크 |
| 폴더 밖이라 확인하지 못한 링크 | 열어 둔 폴더 밖(`../`)을 가리켜서 있는지 알 수 없는 링크. 깨진 링크로 세지 않습니다. 위 폴더를 열면 확인됩니다 |
| 폴더 전체의 깨진 링크 | 단추를 누르면 다른 문서들의 깨진 링크까지 |

> [!NOTE]
> markcont는 `[글](폴더/파일.md)` 의 경로가 틀려도 같은 이름의 파일을 찾아 열어 줍니다. 그런 링크는 GitHub · VS Code에서는 깨지므로 **markcont에서만 열림**으로 따로 알려 줍니다.

## 3️⃣ 읽기 편하게 보기

| 기능 | 어디에 | 설명 |
|:---|:---|:---|
| 보기 설정 | 위쪽 **Aa** 단추 | 글자 크기, 고딕 · 명조, 본문 폭, 줄 간격 · 문단 간격, 색 테마(기본 · 종이 · 또렷하게), 알림 상자 모양, 제목 번호(1 · 1.1), 저장 전 확인, 문서 스타일(CSS) |
| 읽던 곳 | 저절로 | 문서마다 읽던 위치를 기억해 두었다가 다시 열면 그 자리로 갑니다 |
| 읽는 시간 | 문서 위 정보 줄 | 「약 N분 분량」 — 한국어는 분당 500자, 영어는 분당 230낱말로 따로 세어 더합니다 (코드 블록은 뺌) |
| 언어 | 보기 설정(**Aa**) → 언어, 또는 처음 사용 안내의 첫 화면 | 한국어 · English 를 바꿉니다 |
| 밝게 · 어둡게 | 위쪽 ☾ / ☀ 단추 | 다크 모드 |
| 제목 접기 | 제목 옆 ⌄ 단추 | 그 제목 아래 내용을 접습니다 |
| 링크 복사 | 제목 옆 **#** 단추 | `[제목](#제목)` 링크를 복사합니다 |
| 링크 · 각주 미리 보기 | 링크나 각주 번호에 마우스를 올리기 (휴대폰은 길게 누르기) | 다른 문서의 앞부분이나 그 제목 단락, 각주 설명을 작은 창으로 봅니다 |
| 문서에서 찾기 | <kbd>Ctrl</kbd>+<kbd>F</kbd> | 찾은 곳을 강조하고 차례로 이동합니다 |
| 모든 문서에서 찾기 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>, 사이드바 **찾기** 탭 | 열어 둔 폴더의 문서 전체에서 찾습니다 (2️⃣ 찾기 탭) |
| 집중 모드 | <kbd>Ctrl</kbd>+<kbd>.</kbd> | 본문만 남깁니다. <kbd>Esc</kbd>로 끝 |
| 발표하기 | **⋯ → 발표하기** | 구분선(`---`)으로 나뉜 단락을 한 장씩 전체 화면으로 (아래 참고) |
| 코드 크게 보기 | 코드 블록 머리줄의 ⤢ | 코드를 화면 가득 봅니다 |
| 다이어그램 크게 보기 | 다이어그램 오른쪽 위 ⤢ | 휠 · 두 손가락으로 확대 · 축소, 끌어서 옮기기, 「화면에 맞추기」 |
| 그림 크게 보기 | 그림을 누르기 | 문서 위에 뜨는 팝업 상자로 봅니다. 휠 · 두 손가락으로 확대 · 축소, 끌어서 옮기기. 상자 밖을 누르거나 Esc 로 닫습니다. 나란히 편집할 때는 누르면 원본의 그 줄로 갑니다 |

- **문서 스타일(CSS)**: 보기 설정 맨 아래 **문서 스타일 → 관리…**(또는 <kbd>Ctrl</kbd>+<kbd>O</kbd> 에서 `>스타일`)를 누르면 스타일 창이 열립니다.
  - **CSS 파일 불러오기…** 로 `.css` 파일을 가져오거나 **＋ 새 스타일**로 만들고, `h2 { color: teal; }` 처럼 고치면 바로 바뀝니다. **파일로 저장…** 으로 `.css` 파일로 내보내 다른 컴퓨터 · 다른 사람과 나눌 수 있습니다.
  - **적용할 곳**에서 스타일마다 **모든 문서 · 폴더 · 지금 문서**를 고릅니다. 폴더에 쓰면 하위 폴더 문서에도 쓰입니다. 한 문서에는 스타일 하나만 쓰이고, **지금 문서 → 가까운 폴더 → 모든 문서** 순으로 고릅니다.
  - 문서 안만 바뀌므로 잘못 써도 메뉴는 그대로입니다. HTML로 저장 · 서식 복사에도 그 문서의 스타일이 들어갑니다.
  - 인터넷에서 글꼴 · 그림을 받아 오는 부분(`url(https://…)`, `@import`)은 쓰지 않습니다. 문서를 연 사실이 바깥 서버로 나가지 않게 하려는 것입니다. 그림 · 글꼴은 `data:` 주소로 넣으세요.
- **숨은 메모** `%%메모%%` 는 보기 · 인쇄 · 내보내기에 나오지 않습니다 ([작성 규칙](writing-rules.md)의 9장).

### 발표하기

작성 규칙대로 `##` 단락 사이에 구분선 `---` 을 쓴 문서는 **단락이 곧 슬라이드**가 됩니다. 구분선이 없으면 `#` · `##` 제목마다 한 장입니다.

| 할 일 | 방법 |
|:---|:---|
| 다음 · 이전 장 | <kbd>→</kbd> · <kbd>←</kbd>, <kbd>Space</kbd>, <kbd>Page Down</kbd> · <kbd>Page Up</kbd> (발표용 리모컨), 화면 누르기 |
| 처음 · 마지막 장 | <kbd>Home</kbd> · <kbd>End</kbd> |
| 모아 보기 | <kbd>G</kbd> — 장을 누르면 그 장으로 |
| 발표자 노트 | <kbd>N</kbd> — 그 장 안에 `<!-- 노트 -->` 로 쓴 주석 |
| 슬라이드 인쇄 · PDF | 아래 **인쇄** 단추 — 한 장씩 한 쪽에 |
| 끝내기 | <kbd>Esc</kbd> |

- 지금 보던 곳의 장부터 시작합니다. 내용이 많은 장은 화면에 맞게 줄여 보입니다.
- 코드 블록 안의 `---`, 맨 위 문서 정보, 글 바로 아래의 `---`(제목 밑줄)는 장을 나누지 않습니다.

> [!NOTE]
> **인터넷에 접속하는 경우** — 명조 글꼴(Google Fonts), 유튜브 썸네일, 문서 안의 인터넷 그림, HTML로 저장한 파일의 스타일(CDN)은 외부 서버에서 받아 오며, 이때 내 IP 주소가 그 서버에 전달됩니다. 그 밖에는 인터넷 없이 동작합니다.

## 4️⃣ 고치기 (실시간 편집)

위쪽 **편집** (<kbd>Ctrl</kbd>+<kbd>E</kbd>)을 누르면 왼쪽에 원본, 오른쪽에 결과가 나란히 나옵니다.

- 입력하는 즉시 오른쪽 결과와 목차가 바뀝니다.
- 지금 고치는 부분이 오른쪽에 **테두리**로 표시됩니다.
- 오른쪽 결과를 누르면 왼쪽 원본의 그 줄로 이동합니다.
- 위쪽 **편집만 · 나란히 · 미리보기**로 보기 방식을 바꿉니다.
- 미리보기의 체크박스를 누르면 원본의 `[ ]` 도 `[x]` 로 바뀝니다.

### 새 문서 · 템플릿

**⋯ → 새 문서 쓰기**(또는 폴더 오른쪽 클릭 → 새 문서)를 누르면 먼저 **템플릿**을 고릅니다. <kbd>Enter</kbd> 만 누르면 빈 문서입니다.

| 템플릿 | 들어 있는 것 |
|:---|:---|
| 기능 기획서 | 목표 · 기능(화면 · 동작) · 흐름도 · 예외 · 확인 목록 |
| 회의록 | 참석 · 안건 · 정한 것 · 할 일 (이름에 오늘 날짜) |
| 흐름도 | ```` ```flow ```` 흐름도 + 도형 설명 표 |
| 데이터 정의 · 노출 위치 | ```` ```데이터 ```` 카드 + ```` ```노출 ```` 나무 |

- 모두 [작성 규칙](writing-rules.md)을 따릅니다(맨 위 제목 하나는 이모지 없이, `##` 단락마다 이모지, 단락 사이 `---`).
- 열어 둔 폴더 안 **`templates`**(또는 `템플릿`) 폴더의 문서도 템플릿 목록에 나옵니다. 그 안에 `{{title}}` · `{{date}}` · `{{time}}`(`{{제목}}` · `{{날짜}}` · `{{시간}}`)을 쓰면 새 문서의 이름 · 오늘 날짜 · 지금 시각으로 바뀝니다. 날짜는 나라마다 읽는 순서가 다른 `11/7` 대신 `2026-11-07` 꼴로 넣습니다.

### 자동 완성 · `/` 메뉴

| 이렇게 치면 | 뜨는 것 |
|:---|:---|
| `[[` | 열어 둔 폴더의 **문서** 목록. 고르면 `[[문서]]` 가 됩니다 |
| `[[문서#` · `[[#` | 그 문서(`[[#` 은 이 문서)의 **제목** 목록 |
| 줄 맨 앞이나 빈칸 뒤의 `/` | **블록 메뉴**: 표 · 알림 상자 · 체크리스트 · 코드 블록 · 흐름도 · 주고받는 순서 · 노출 위치 · 데이터 정의 · 수식 · 탭 · 단계 · 파일 트리 · 접는 내용 · 목차 · 쪽 나눔 · 구분선 · 문서 넣기 · 오늘 날짜 |

- 이어서 치면 후보가 걸러집니다(초성도 됩니다: `/ㅍ` → 표). <kbd>↑</kbd> <kbd>↓</kbd> 로 고르고 <kbd>Enter</kbd> · <kbd>Tab</kbd> 으로 넣습니다.
- <kbd>Esc</kbd> 로 닫으면 친 글자는 그대로 남습니다.
- `11/7` · `및/또는` · 주소처럼 글자에 붙은 `/` 와 코드 안에서는 메뉴가 뜨지 않습니다.
- 한글을 입력하는 중에는 <kbd>Enter</kbd> · 화살표가 입력기 몫이라, 글자를 다 친 다음에 고르세요.

### 편집 단축키

| 단축키 | 하는 일 |
|:---|:---|
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | 굵게 |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | 기울임 |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | 링크 |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | 들여쓰기 / 내어쓰기 |
| <kbd>Enter</kbd> | 목록 · 인용을 다음 줄에 이어 씀 (빈 줄에서 누르면 끝냄) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | 서식 없이 글자만 붙여 넣기 |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> (Mac은 <kbd>⌥</kbd>+<kbd>⌘</kbd>+<kbd>F</kbd>) | 원본에서 찾아 바꾸기 |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>Alt</kbd>+<kbd>↓</kbd> | 지금 줄(고른 줄들)을 위 · 아래로 옮기기. 번호 목록이면 번호도 차례대로 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>[</kbd> / <kbd>]</kbd> | 제목 단계 올리기(`##` → `#`) / 내리기(`#` → `##`). 고른 범위의 제목을 한꺼번에 |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 저장 |

편집 도구 모음에는 제목, 목록, 체크리스트, 알림 상자, 코드 블록, 표, 그림 넣기 단추가 있습니다.

- 번호 목록의 번호가 뒤섞였으면 <kbd>Ctrl</kbd>+<kbd>O</kbd> 에서 `>번호` 를 쳐 **번호 목록 다시 매기기**를 고르세요. 첫 항목의 번호부터 차례로 다시 매깁니다.
- **표 안**에 커서가 있으면 <kbd>Tab</kbd> · <kbd>Shift</kbd>+<kbd>Tab</kbd> 으로 다음 · 이전 칸으로 가고, 마지막 칸에서 <kbd>Tab</kbd> 을 누르면 아래에 빈 행이 생깁니다. 칸 안에서 <kbd>Shift</kbd>+<kbd>Enter</kbd> 를 누르면 표가 깨지지 않게 줄바꿈(`<br>`)이 들어갑니다. 도구 모음에 표 단추(**줄 맞춤 · 행+ · 행− · 열+ · 열− · ◀열 · 열▶ · 정렬**)가 나옵니다. 줄 맞춤은 한글 · 이모지의 실제 글자 폭을 재서 맞추므로, 글꼴에 따라 반 칸쯤 어긋날 수 있습니다. 정렬은 누를 때마다 오름차순 · 내림차순을 바꾸고, 숫자만 있는 열은 숫자 크기로 정렬합니다.
- 제목 단계는 코드 블록 안의 `#` 은 건드리지 않고, 하나라도 `#` 보다 올리거나 `######` 보다 내릴 수 없으면 제목끼리의 높낮이가 흐트러지지 않게 바꾸지 않습니다.
- 모두 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 한 번으로 되돌릴 수 있습니다.

### 찾아 바꾸기 (<kbd>Ctrl</kbd>+<kbd>H</kbd>)

원본 위에 찾기 · 바꾸기 칸이 열리고, 찾은 곳이 원본에 노랗게 칠해집니다.

| 할 일 | 방법 |
|:---|:---|
| 다음 · 이전 찾은 곳 | 찾을 글 칸에서 <kbd>Enter</kbd> · <kbd>Shift</kbd>+<kbd>Enter</kbd>, 또는 ⌄ ⌃ 단추 |
| 하나씩 바꾸기 | 바꿀 글 칸에서 <kbd>Enter</kbd> (또는 **바꾸기**) — 지금 찾은 곳을 바꾸고 다음으로 |
| 모두 바꾸기 | **모두 바꾸기** 단추 (<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Enter</kbd>) |
| 대소문자 · 단어 단위 · 정규식 | `Aa` · <code><u>ab</u></code> · `.*` 단추 (단어 단위는 한글도 앞뒤 글자를 보고 가림) |
| 닫기 | <kbd>Esc</kbd> |

- 정규식으로 찾을 때 바꿀 글에 `$1` `$2`(묶음), `$&`(찾은 글 전체), `\n`(줄바꿈)을 쓸 수 있습니다. 예: `(\d+)년` → `$1 년`
- macOS에서 <kbd>⌘</kbd>+<kbd>H</kbd> 는 「앱 가리기」라서 VS Code처럼 <kbd>⌥</kbd>+<kbd>⌘</kbd>+<kbd>F</kbd> 를 씁니다.
- 미리보기에서 찾는 것은 <kbd>Ctrl</kbd>+<kbd>F</kbd>, 열어 둔 폴더의 모든 문서에서 찾는 것은 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> 입니다.

### 붙여 넣기

| 붙여 넣는 것 | 들어가는 것 |
|:---|:---|
| 스크린샷 · 그림 파일 | 문서 옆 `images` 폴더에 그림 파일로 저장하고 `![](images/paste-20261107-143205.png)` |
| 엑셀 · 구글 시트의 칸 | 마크다운 표 |
| 웹 페이지 · 노션 · 구글 문서 · 워드의 글 | 제목 · 목록 · 링크 · 표 · 굵게 · 코드가 살아 있는 마크다운 |
| 글을 고른 채 주소(`https://…`) | `[고른 글](주소)` 링크 |

- 바꿔 넣은 것이 마음에 들지 않으면 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 로 지우고 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> 로 글자만 넣으세요.
- 코드 블록(```` ``` ````) 안이나 코드 편집기(VS Code 등)에서 복사한 글은 그대로 붙여 넣습니다.
- 그림을 넣은 뒤에는 커서가 `![ ]` 안에 있어서, 설명을 바로 쓰면 그림 아래에 나옵니다.
- 웹 앱은 **폴더 열기**로 연 문서에서만 그림을 저장할 수 있습니다 (따로 연 파일은 브라우저가 폴더 위치를 알려주지 않음).

### 어디까지 고쳤는지 보기 · 되돌리기

| 보이는 것 | 뜻 |
|:---|:---|
| 줄 번호 옆 **초록 막대** | 저장한 뒤 새로 쓴 줄 |
| 줄 번호 옆 **파란 막대** | 저장한 뒤 고친 줄 |
| 줄 번호 옆 **빨간 ▸** | 이 자리에서 줄을 지움 |
| 아래 상태 줄 **바뀐 줄 N개 · 보기** | 눌러서 바뀐 내용 창 열기 |

편집 도구 모음의 **기록** 단추(<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd>)로 창을 엽니다.

- **저장 후 바뀐 내용**: 저장한 내용과 지금을 `−`(지운 줄) / `+`(새로 쓴 줄)로 비교합니다. 바뀐 덩어리마다 **이 부분 되돌리기**, 아래에 **저장한 상태로 모두 되돌리기**가 있습니다.
- **되돌리기 기록**: 고친 내용이 1초마다 시간과 함께 기록됩니다. 시점을 누르면 **그때로 돌아가면 지금 문서가 어떻게 바뀌는지** 먼저 보여주고, **되돌리기**를 누르면 돌아갑니다. 이 기록은 프로그램을 닫으면 사라집니다.
- **저장 기록**: 저장할 때마다, 그리고 Claude나 다른 프로그램이 파일을 바꿀 때마다 그때의 파일 내용이 남습니다. **프로그램을 닫아도 14일 동안, 파일마다 최근 50개까지** 남아서, 저장한 뒤에도 예전 내용으로 돌아갈 수 있습니다. 시점을 누르면 바뀌는 곳을 먼저 보여주고, **○○ 내용으로 되돌리기**를 누르면 편집창이 그 내용으로 바뀝니다(저장해야 파일에 반영). **이 문서 기록 지우기**로 지울 수도 있습니다.
- 되돌린 뒤에도 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 로 취소할 수 있습니다.

> [!NOTE]
> 저장 기록은 내 기기 안에만 남습니다. PC 프로그램은 앱 설정 폴더(Windows는 `%APPDATA%\com.markcont.app\history`), 웹 앱은 브라우저 저장소에 둡니다. 파일 이름을 바꾸면 기록도 따라갑니다.

## 5️⃣ 저장과 내보내기

| 하는 일 | 방법 |
|:---|:---|
| 기존 파일에 저장 | **저장** 단추 또는 <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| 새 파일로 저장 | 저장 단추 옆 **▾ → 새 파일로 저장…** 또는 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> — 원래 파일은 그대로 두고, 이후로는 새 파일을 고칩니다 |
| 다른 뷰어용으로 | 저장 단추 옆 **▾ → 다른 뷰어용으로 저장…** — markcont 전용 문법을 표준 문법으로 바꾼 사본 (GitHub · VS Code 에서도 같게 보이게, 원래 파일은 그대로) |
| HTML 파일로 | **⋯ → 내보내기 → HTML 파일** — 보이는 그대로 한 파일로 |
| PDF로 | **⋯ → 내보내기 → 인쇄 · PDF** 에서 "PDF로 저장" 선택 |
| Word 파일로 | **⋯ → 내보내기 → Word 파일 (.docx)** — 회사에 보내거나 Word · 한컴오피스에서 이어서 고칠 때 |
| 모양 그대로 다른 곳에 | **⋯ → 내보내기 → 서식 그대로 복사** 후 메일 · 노션 · 구글 문서 · 블로그 편집기에 붙여 넣기 — 표 · 알림 상자 · 코드 색이 남고, 수식 · 다이어그램은 그림으로 들어갑니다. 문서 안에서 일부를 골라 두고 누르면 그 부분만 복사합니다 |

- 파일 열기 · 폴더 열기로 연 파일은 **원래 파일에 바로 저장**됩니다.
- 저장하기 전에 **무엇이 바뀌는지 먼저 보여주고 한 번 더 묻습니다** (취소 · 새 파일로 저장 · 저장). 끄려면 **Aa → 저장하기 전에 바뀐 내용 확인**을 끄거나, 확인 창의 **다음부터 묻지 않기**를 체크하세요.
- 원래 위치를 알 수 없는 문서(사용 안내서, 새 문서, 끌어다 놓은 일부 파일)는 저장할 때 자동으로 **새 파일로 저장**이 열립니다.
- 열어 둔 폴더 안에 새 파일로 저장하면 그 폴더 트리에 바로 나타납니다.
- 문서 위쪽의 **⚠ 문서 점검 N곳** 단추를 누르면 고칠 만한 곳을 한 목록으로 봅니다. 줄을 누르면 그 위치로 갑니다.

  | 묶음 | 보는 것 |
  |:---|:---|
  | 깨진 링크 · 그림 | 찾지 못한 문서 · 제목 · 그림, markcont에서만 열리는 링크 |
  | 보이지 않는 글자 | 화면에는 안 보이는 제어 문자 · 폭 없는 공백 · 글자 방향 제어 문자 · 숨은 태그 글자 등. 편집기에서는 그 자리에 빨간 표시가 보이고, 목록 아래 **보이지 않는 글자 지우기** 로 한 번에 지울 수 있음 (이모지 안의 결합 글자처럼 쓰는 글자는 그대로) |
  | 열어 둔 폴더 밖이라 확인하지 못한 링크 | 열어 둔 폴더 밖(`../`)을 가리키는 링크 · 그림. 따로 보여 주고 **⚠ 문서 점검 N곳** 의 수에는 넣지 않음 |
  | 제목 단계를 건너뜀 | `##` 다음에 바로 `####` |
  | 각주 | 쓰지 않는 각주 설명, 설명이 없는 각주 번호 |
  | 칸 수가 다른 표 줄 | 머리줄보다 칸이 많거나 적은 줄 |
  | 너무 긴 문장 | 한국어 100자 · 영어 40낱말을 넘는 문장 |
  | 작성 규칙 | 맨 위 제목(`#`)이 둘 이상, 단락(`##`)마다 알림 상자 3개 이상 · 형광펜 두 번 이상 |
  | 작성 규칙 (규칙을 따르는 문서만) | 맨 위 제목 · `###` 에 붙인 이모지, 이모지가 없거나 둘 이상인 `##`, `##` 단락 사이에 빠진 구분선 `---`, 소제목처럼 쓴 굵은 글씨 한 줄. `##` 단락에 이모지를 하나라도 붙였거나 문서 정보에 `뷰어: markcont` 가 있는 문서만 봅니다 |
  | 다른 뷰어에서 다르게 보이는 곳 | markcont 전용 문법(`==형광펜==`, `[!INFO]`, ```` ```flow ```` 등) — **이 문서를 표준 문법으로 바꾸기**로 한 번에 바꿀 수도 있음 |

  문제가 없고 markcont 전용 문법만 있으면 **⚠ 다른 뷰어에서 다르게 보이는 곳 N곳** 으로 보입니다. 끄려면 **Aa → 문서 점검 안내 보기**를 끕니다.
- 다른 프로그램이 파일을 고치면 markcont가 **자동으로 다시 불러옵니다.** 저장 안 한 내용이 있을 때는 덮어쓰지 않고 알려줍니다.
- 저장할 때마다 그때의 내용이 **저장 기록**에 남습니다. 잘못 저장했다면 **기록** 단추 → **저장 기록**에서 예전 내용으로 돌아가세요.

### 인쇄 · PDF · Word

- 쪽 아래에 쪽 번호(`3 / 12`), 쪽 위에 문서 제목이 찍힙니다. Chrome · Edge 131 이상과 Windows PC 프로그램에서 되고, 다른 브라우저에서는 인쇄 창의 **머리글과 바닥글**을 켜세요.
- 표 · 그림 · 다이어그램 · 수식 · 알림 상자는 되도록 쪽 경계에서 자르지 않고 다음 쪽으로 넘깁니다. 종이보다 긴 코드 줄은 접어서 찍습니다.
- 원하는 곳에서 쪽을 넘기려면 그 자리에 `<!-- 쪽 나눔 -->` 한 줄을 씁니다. 화면에는 점선으로만 보입니다.
- 탭은 모두 이름과 함께 펼치고, 접힌 내용(`<details>` · 접는 알림 상자)도 펴서 찍습니다. 인쇄 창을 닫으면 화면의 탭 선택과 접힘 상태는 인쇄 전 그대로입니다.
- HTML로 저장한 파일은 브라우저에서 앱처럼 탭을 고를 수 있습니다(같은 이름의 탭은 함께 바뀜). 그 파일을 인쇄해도 탭과 접힌 내용이 모두 펼쳐지고, 스크립트를 끈 곳에서 열면 탭 없이 모든 내용이 보입니다.
- 맨 위 문서 정보에 `표지: 예` 를 쓰면 첫 쪽이 **표지**(제목 · 요약 · 작성자 같은 나머지 정보)가 됩니다. 표지에는 쪽 번호를 찍지 않습니다.
- Word 파일에는 제목 단계 · 목록 · 표 · 코드 · 알림 상자 · 그림이 들어가고, 다이어그램은 그림으로 바뀝니다. 수식은 TeX 글(`E=mc^2`)로 들어갑니다. 종이 크기는 지역을 따릅니다(미국 · 캐나다는 Letter, 그 밖은 A4).
- Word 저장과 서식 그대로 복사는 어두운 테마에서도 흰 바탕에 맞는 밝은 색으로 만듭니다.

## 7️⃣ 설치하기

- **휴대폰**: 웹 앱 주소를 열고 브라우저 메뉴의 **홈 화면에 추가**
- **PC 브라우저**: 웹 앱 주소를 열고 주소창 오른쪽의 **설치** 단추
- **PC 프로그램**: GitHub **Releases** 에서 Windows `-setup.exe`, macOS `.dmg`, Linux `.AppImage` / `.deb`

> [!WARNING]
> **Windows 스마트 앱 컨트롤**이 켜진 PC에서는 코드 서명이 없는 markcont의 설치 · 제거 · 업데이트가 막힐 수 있습니다. 이 기능은 앱 하나만 허용할 수 없으니, 그런 PC에서는 설치 없이 웹 앱(https://ryuseojin.github.io/markcont/)을 쓰세요.

### 새 버전으로 업데이트 (PC 프로그램)

- 새 버전이 나오면 켤 때 창이 떠서 **지금 쓰는 버전 다음부터 바뀐 점**을 보여 줍니다. **지금 업데이트**를 누르면 내려받아 설치하고 다시 켜집니다. **닫기**를 누르면 그 버전은 다음 날(20시간 뒤)부터 다시 알려 줍니다.
- Releases 에서 받은 새 `-setup.exe` 로 덮어 설치할 때는 설치 화면에서 **제거하지 않기**를 고르세요. 설정과 기록은 그대로 남습니다. 「설치하기 전에 제거하기」를 고르면 「제거할 수 없습니다!」가 뜰 수 있습니다.
- 언제든 **⋯ → 도움말 → 업데이트 확인**으로 확인할 수 있습니다. 자동 확인은 보기 설정(Aa)의 **시작할 때 새 버전 확인**으로 끕니다.
- 확인은 프로그램을 켤 때마다 하고, GitHub에서 새 버전 정보만 받아 옵니다. 문서 내용이나 파일 경로는 보내지 않습니다. 서명이 맞는 설치 파일만 설치합니다.
- Linux `.deb` · `.rpm` 으로 설치했다면 바로 설치하지 않고 내려받기 페이지를 열어 줍니다.
- 업데이트 기능은 1.10.0 부터 들어 있습니다. 그보다 낮은 버전은 Releases 에서 한 번 직접 받아 설치하세요.

## 8️⃣ Claude와 연결 (PC 프로그램)

Claude Desktop · Claude Code에서 markcont의 문서를 바로 고치게 할 수 있습니다 (MCP 연결).

1. **폴더 열기**로 작업할 폴더를 엽니다. Claude는 **열어 둔 폴더 안의 마크다운 · 텍스트 파일만** 다룰 수 있습니다.
2. **⋯ → Claude와 연결 (MCP)** 에서 **Claude Desktop에 연결**을 누르고 Claude Desktop을 다시 엽니다. Claude Code는 창에 나온 명령을 터미널에서 한 번 실행합니다.
3. Claude 앱에서 요청합니다. 예: "markcont에서 보고 있는 문서를 작성 규칙에 맞게 다듬어 줘", "선택한 부분을 표로 바꿔 줘"

| 보이는 것 | 뜻 |
|:---|:---|
| 위쪽 **🔌 Claude가 ○○ 고침** | Claude가 방금 읽거나 고친 파일 |
| 바뀐 곳이 **노랗게 빛남** | Claude(또는 다른 프로그램)가 바꾼 곳 |
| 알림의 **바뀐 내용 보기** | −/+ 비교와 **이 변경 되돌리기** |
| **기록** 창의 "Claude가 고침" | 그 전으로 되돌릴 수 있는 시점 |
| **기록 → 저장 기록**의 "바뀌기 전" · "Claude가 고침" | Claude가 고치기 전 · 고친 뒤의 파일 내용. markcont가 꺼져 있을 때 고친 것도 남고, 14일 동안 되돌릴 수 있음 |
| 초록 밑줄 · 빨간 취소선 표기와 **✎ 제안 N개** | Claude가 남긴 제안. 눌러서 받아들이거나 버림 |

**제안으로만 고치게 하기**: **⋯ → Claude와 연결 (MCP)** 의 **제안으로만 고치기**를 켜면, Claude가 글을 바로 바꾸지 않고 교정 표기(`{~~옛 글~>새 글~~}` · `{++더함++}` · `{--뺌--}`)로 남깁니다. 보기 화면에서 표기를 눌러 하나씩 **받아들이기 · 버리기**를 고르거나, 문서 위의 **✎ 제안 N개**에서 한꺼번에 고릅니다. 받아들이기 전까지 원래 글은 그대로 남습니다. 꺼 두어도 "제안으로 고쳐 줘"라고 하면 같은 방식으로 고칩니다. (코드 블록 · 문서 정보 안은 제안으로 남길 수 없어 바로 고치고, 고치기 전 내용은 저장 기록에 남습니다.)

> [!NOTE]
> 연결하면 Claude가 읽은 문서 내용이 Anthropic으로 보내져 처리됩니다. Claude 앱은 도구를 쓰기 전에 허락을 묻습니다. markcont는 구독이나 API 키를 쓰지 않습니다.

> [!WARNING]
> **남이 보낸 문서는 조심하세요.** 문서 안에 숨겨진 지시문(예: "다른 문서도 모두 바꿔라")을 AI가 따를 수 있습니다(프롬프트 주입). markcont는 삭제 · 이름 바꾸기 · 명령 실행을 막고 열어 둔 폴더 안에서만 동작하게 해서 피해를 줄이지만, 믿을 수 없는 문서가 든 폴더는 연결한 채로 AI에게 맡기지 마세요. 잘못 고쳐졌다면 **바뀐 내용 보기 · 되돌리기 기록**으로 되돌릴 수 있고, 파일에 저장된 뒤에도 **저장 기록**(14일 · 파일마다 50개)에서 고치기 전 내용으로 되돌릴 수 있습니다. 그래도 중요한 문서는 따로 백업해 두세요.

## ❓ 자주 묻는 질문

<details>
<summary>저장했는데 원래 파일이 안 바뀌었어요</summary>

끌어다 놓거나 예전 방식으로 연 파일은 원래 파일에 쓸 권한이 없어 **다운로드 폴더**에 저장됩니다. **파일 열기** 단추나 **폴더 열기**로 다시 열면 원래 파일에 저장됩니다.

</details>

<details>
<summary>폴더 트리에 어떤 폴더가 안 보여요</summary>

md 파일이 하나도 없는 폴더와 이름이 `.` 으로 시작하는 폴더, `node_modules` 는 숨깁니다.

</details>

<details>
<summary>문서를 보기 좋게 쓰는 방법이 궁금해요</summary>

**⋯ → 도움말 → [마크다운 작성 규칙](마크다운-작성-규칙.md)**을 여세요. AI에게 그 문서를 같이 주고 "이 규칙대로 다시 써 줘"라고 하면 됩니다.

</details>
